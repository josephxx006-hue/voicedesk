FAQ

Does VoiceDesk use my personal phone?

No. This prototype works without phone access. Real business phone and WhatsApp connections can be added later.

Do I need an API key?

Not for this prototype. The current receptionist uses a local response engine so you can test the product first.

Can I use it for any business?

Yes, the setup is designed around your business information. The first target can be salons, barbershops and other appointment-based businesses.

Will customer data be saved?

This prototype saves data in the browser on the device. A secure cloud database will be added before real customers use the service.
